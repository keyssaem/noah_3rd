 <인공지능 로봇과 올바른 관계 맺기 시뮬레이터>
  : AI 전학생 '노아'와 함께하는 공존·상생 프로젝트

 사 용 안 내
════════════════════════════════════════════════════════════

초등학교 6학년 도덕 수업을 위한 3D 시뮬레이션형 교육용 웹앱입니다.
학생은 AI 전학생 '노아'와 같은 하루를 두 번 살아 보면서, 인공지능 로봇을
'단순한 도구로 대하는 관계'와 '도덕에 기반을 둔 존중의 관계'를 견주어 보고,
노아를 어떻게 대할 것인지 스스로 답과 약속을 정하게 됩니다.

 * 적용 성취기준 : [6도02-03] 인간과 인공지능 로봇 간의 다양한 관계를
                  파악하고, 도덕에 기반을 둔 관계 형성의 필요성을 탐구한다.
 * 핵심 질문     : 인공지능 로봇과 친구가 될 수 있을까?
                  친구가 아니더라도 어떻게 관계를 맺어야 할까?
 * 대상          : 초등학교 6학년
 * 형태          : 설치와 빌드가 필요 없는 웹앱 (회원가입·로그인 없음)
 * 공식 접속 주소 : 인공지능노아.kr
 * 안내          : 이 웹앱에는 AI 생성 미디어가 포함되어 있습니다.


────────────────────────────────────────────────────────────
 1. 실행 방법
────────────────────────────────────────────────────────────

 [권장] 웹 주소로 접속하기
   최신 Chrome 또는 Edge 브라우저에서 아래 주소로 접속합니다.

       인공지능노아.kr

   설치·회원가입·빌드가 필요 없으며, 접속 즉시 바로 실행됩니다.
   카메라를 사용하는 활동까지 온전히 체험하려면 이 방법을 권장합니다.
   (카메라 기능은 보안 정책상 HTTPS 주소에서만 동작합니다.)

 [보조] 제출 파일의 index.html 직접 실행하기
   제출 폴더의 index.html 파일을 브라우저로 열어도 실행됩니다.
   - 인터넷에 연결되어 있으면 자동으로 공식 주소로 이동합니다.
   - 인터넷이 없으면 오프라인 모드로 실행되며, 3D 모델과 카메라 기능이
     제한될 수 있습니다. 이 경우에도 게임은 대체 캐릭터와 버튼 조작으로
     끝까지 진행됩니다.


────────────────────────────────────────────────────────────
 2. 실행 환경
────────────────────────────────────────────────────────────

 - 권장 브라우저 : WebGL을 지원하는 최신 Chrome 또는 Edge
 - 권장 기기     : PC(키보드·마우스), 태블릿(터치)  — 화면이 클수록 좋습니다
 - 인터넷        : 카메라 손 인식 기능에만 필요 (그 외 자산은 모두 내장)
 - 소리          : 배경 음악과 효과음이 있어 스피커 또는 이어폰 사용을 권장
 - 별도 설치     : 없음 (프로그램 설치, 플러그인, 계정 모두 불필요)

 ※ 3D 그래픽, 폰트, 영상, 배경 음악은 모두 프로젝트 안에 포함되어 있어
    학교 네트워크가 잠시 끊겨도 수업이 중단되지 않습니다.


────────────────────────────────────────────────────────────
 3. 조작 방법
────────────────────────────────────────────────────────────

   동작            │ PC                        │ 태블릿·터치 기기
  ─────────────────┼───────────────────────────┼──────────────────
   이동            │ W A S D 또는 방향키        │ 왼쪽 아래 조이스틱
   점프            │ Space                     │ 오른쪽 아래 ⬆ 버튼
   상호작용·대화   │ F                         │ 오른쪽 아래 F 버튼
   대화 넘기기     │ 대화창 클릭, Space, Enter │ 대화창 터치
   원칙 카드 획득  │ 가까이서 점프 또는 클릭    │ 가까이서 점프 또는 터치
   도덕 수첩       │ 화면 왼쪽 위 📔 버튼       │ 동일
   설정            │ 화면 오른쪽 위 ⚙️ 버튼      │ 동일

 - 게임을 시작하면 접속한 기기에 맞는 조작 안내 팝업이 먼저 표시됩니다.
 - 다음에 갈 곳은 빛기둥과 화면 위쪽 안내 문구(📌)로 알려 줍니다.
 - 어디로 갈지 모를 때는 화면 위쪽의 안내 문구를 확인해 주세요.


────────────────────────────────────────────────────────────
 4. 학습의 흐름
────────────────────────────────────────────────────────────

  1단계  도입    이름과 캐릭터를 정하고 집에서 조작법을 익힙니다.
  2단계  탐색    등굣길에서 '로봇 3원칙' 카드를 모읍니다.
  3단계  첫째 날  노아와 하루를 보내며 다섯 가지 상황을 경험합니다.
  4단계  전환    그 하루가 어떤 관계였는지 스스로 확인하게 됩니다.
  5단계  둘째 날  같은 하루를 다른 태도로 다시 살아 봅니다.
  6단계  성찰    처음과 같은 질문에 다시 답하고, 나만의 약속을 정합니다.

 - 마지막에는 학생이 직접 쓴 답과 그림, 서명이 담긴 '약속 헌장' 이미지가
   만들어지며 파일로 내려받을 수 있습니다. (수업 산출물로 활용 가능)
 - O와 X 중 어느 답도 오답으로 처리하지 않습니다. 이 작품의 결론은
   '친구가 될 수 있는가'보다, 친구 여부와 관계없이 도덕에 기반을 둔 관계를
   맺어야 한다는 데 있습니다.

 ※ 작품의 핵심 장치가 중반의 반전에 있어, 이 안내문에서는 줄거리를
    자세히 밝히지 않았습니다. 전체 내용과 설계 의도는 함께 제출한
    README 문서에 모두 정리해 두었습니다.


────────────────────────────────────────────────────────────
 5. 살펴보실 때 도움이 되는 기능
────────────────────────────────────────────────────────────

 - 인트로 영상 : 재생 10초 뒤 '건너뛰기' 버튼이 나타납니다.

 - 장면 바로가기 : 화면 왼쪽 위의 📔 도덕 수첩 버튼을 짧은 시간 안에
   5회 연속 누르면 단계별 장면 이동 패널이 열립니다. 처음부터 진행하지
   않고 특정 장면만 확인하실 때 사용하실 수 있습니다.
   (수업 중에는 사용하지 않는 검수용 기능입니다.)

 - 4자리 잠금 다이얼 : 중반에 4자리 숫자를 입력하는 장면이 있습니다.
   정답은 7942 이며, 실제 수업에서는 활동지의 힌트를 보고 학생이
   '친(7)구(9) 사(4)이(2)'로 추론하도록 설계했습니다.

 - 설정(⚙️) : 효과음, 배경 음악, 대사 읽어주기(TTS), 글자 크기(보통/크게/
   아주 크게)를 조절할 수 있고, 처음부터 다시 시작할 수 있습니다.


────────────────────────────────────────────────────────────
 6. 카메라 사용과 개인정보
────────────────────────────────────────────────────────────

 - 이 앱은 별도의 서버나 데이터베이스를 사용하지 않습니다.
   학생이 입력한 내용은 외부로 전송되지 않으며, 사용 중인 브라우저 안에만
   임시로 저장됩니다.

 - 카메라는 '얼굴 스캔' 장면과 '가위바위보' 활동에서만 사용하며,
   사용 전에 처리 방식과 거절할 수 있다는 점을 반드시 안내합니다.
   카메라 영상은 브라우저 안에서만 처리되고 저장·전송하지 않으며,
   활동이 끝나면 즉시 종료됩니다.

 - 카메라를 거절하거나 사용할 수 없는 환경에서는 버튼 조작 방식으로
   똑같이 진행되므로, 체험에 어떤 제약도 없습니다.

 - 이야기 속 '얼굴 데이터 저장' 장면은 개인정보의 중요성을 다루기 위한
   연출이며, 실제로 얼굴 사진이나 영상이 저장되지는 않습니다.

 - 공용 기기 사용 시 : 엔딩까지 정상적으로 마치면 학생의 입력 기록이
   자동으로 삭제됩니다. 도중에 창을 닫아 기록이 남았을 경우에는
   ⚙️ 설정 → 처음부터 다시 시작 → [전부 지우고 완전히 처음부터]를
   선택하면 모두 지워집니다.


────────────────────────────────────────────────────────────
 7. 이럴 때는 이렇게
────────────────────────────────────────────────────────────

 · 3D 화면이 열리지 않을 때
     크롬 오른쪽 위 ⋮ → 설정 → 시스템 →
     '가능한 경우 그래픽 가속 사용'을 켠 뒤 브라우저를 완전히 다시 시작합니다.
     (앱 안에도 같은 안내 화면과 새로고침 버튼이 나타납니다.)

 · 캐릭터가 단순한 상자 모양으로 보일 때
     3D 모델 파일을 불러오지 못한 경우입니다. 내용 진행에는 지장이 없으며,
     공식 주소(인공지능노아.kr)로 접속하면 정상적으로 표시됩니다.

 · 카메라가 동작하지 않을 때
     자동으로 버튼 방식으로 전환되어 그대로 진행됩니다.

 · 영상이 재생되지 않을 때
     해당 장면을 건너뛰고 다음 장면으로 이어집니다.

 · 화면이 멈춘 것 같을 때
     새로고침(F5) 후 이어서 진행할 수 있습니다.

 ※ 안정적인 수업 운영을 위해 위와 같은 상황에서도 활동이 끊기지 않도록
    모든 기능에 대체 수단을 마련해 두었습니다.

 8. 저작권 및 AI 생성 미디어 안내
────────────────────────────────────────────────────────────

 - 사용한 미디어의 저작권 증빙 자료는 제출 폴더의
